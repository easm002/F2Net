# Datasets

Preparation scripts for the two UHR benchmarks used in the paper:

- `prepare_deepglobe.py` — DeepGlobe Land Cover (803 × 2448×2448, 7 classes)
- `prepare_inria.py` — Inria Aerial Image Labeling (180 × 5000×5000, binary)

See [docs/dataset_prepare.md](../docs/dataset_prepare.md) for download
links, usage and output layout.
